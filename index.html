OS image

Stage 3 writes the same image to every board: the station's Raspberry Pi OS Lite (built here), or an image of your own uploaded below. The settings under it go to each board's boot partition as cloud-init files (as Raspberry Pi Imager does), so saving applies them to the boards flashed from then on, without a rebuild; an uploaded image without cloud-init boots with its own configuration instead.

    Provision

    1. Insert the target SD card into the board.
    2. Hold the power button, connect USB-C to this station, release the button.
    3. Click Connect board and pick BCM2712 Boot in Chrome's list.
    4. Click Provision. When asked, click Connect fastboot gadget and pick Raspberry Pi ….
    The server is not reachable. Provisioning needs it (it holds the board secrets and builds every file). Start it with python server.py and reload.
