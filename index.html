    Provision

    1. Insert the target SD card into the board.
    2. Hold the power button, connect USB-C to this station, release the button.
    3. Click Connect board and pick BCM2712 Boot in Chrome's list.
    4. Click Provision. When asked, click Connect fastboot gadget and pick Raspberry Pi ….
    The server is not reachable. Provisioning needs it (it holds the board secrets and builds every file). Start it with python server.py and reload, or use the manual mode with local directories.

                    rpi-fastbootd), stage image.json from an rpi-image-gen output directory; the board creates
                    its partitions and LUKS2 containers itself, then the station flashes each sparse image the board asks for
                    (oem idpgetblk). Sparse files above max-download-size (256 MiB) are refused here;
                    the server splits them.
